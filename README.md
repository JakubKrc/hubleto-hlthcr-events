# Hlthcr Events

Events with attendees and car bookings, calendars.

Hubleto app of the Hlthcr set (occupational health service, Slovakia). Namespace: `Hubleto\App\External\WaiBlue\HlthcrEvents`.
Needs: `wai-blue/hubleto-hlthcr-core`.

## Install into a Hubleto project

```bash
composer config repositories.wai-blue/hubleto-hlthcr-events vcs <repository-url>
composer require wai-blue/hubleto-hlthcr-events:dev-main
php hubleto app install "Hubleto\App\External\WaiBlue\HlthcrEvents"
npm run build
```
